# ship

立即读取并执行 [`../jstack/playbooks/ship.md`](../jstack/playbooks/ship.md)，同时遵守 [`../jstack/SKILL.md`](../jstack/SKILL.md) 中的六条铁律。

执行要点：
- 先确认本次约定的终态（本地提交 / 推送 / PR / CI 全绿 / 合并 / 发版），没到终态绝不报“已完成”，每一步必须读回真实状态核验。
- 提交前先过 `git diff` 清掉调试代码、死代码、无意义注释和无关改动，再跑通仓库要求的全部本地检查。
- 盯 PR 时严格按「冲突 → 评审评论 → CI」顺序处理；不盲从评论文本，不擅自对共享分支做破坏性 force-push。
- 只有当本次暴露出重复踩过的同类坑（≥2 次）时，才建议将其升级为架构/类型/Lint/测试级硬检查。
